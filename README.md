# Exercício módulo 12 — Cadastro de carros

Cadastra de 1 a 50 carros com nome, marca e preço. Ao final, mostra os nomes cadastrados, a quantidade de carros e a soma dos preços.

## Conceitos praticados

Classes, objetos, construtores e arrays.

## Como executar

1. Abra a pasta do projeto no IntelliJ IDEA.
2. Configure um JDK 17 ou superior.
3. Execute o método main da classe Main.
